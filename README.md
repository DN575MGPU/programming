Задание: Кадровая служба

Создать классы:

Базовый класс 1: Employee (оклад)

Дочерние классы 1: Developer (грейд), Designer (портфолио)

Базовый класс 2: Department (назв.)

Дочерний класс 2: ITDepartment (проекты)

Контейнер: Team

Полиморфный метод (бизнес-логика): calculate_bonus() (15% для разраб., 10% для диз.)

Описание реализованной логики

Общая концепция: 
Система представляет собой управление персоналом с возможностью расчёта бонусов для разных типов сотрудников и отделов. Реализованы ключевые принципы ООП: наследование, полиморфизм и композиция.

1. Наследование (Иерархия классов):
Базовый класс Employee хранит общую информацию о сотруднике: ФИО, ID, оклад, содержит базовые методы: calculate_bonus() (возвращает 0) и display_info()

Базовый класс Department хранит название отдела, предоставляет методы get_department_type() и get_bonus_multiplier()

Дочерний класс ITDepartment добавляет поле projects (список проектов), переопределяет get_bonus_multiplier() → возвращает 1.1 (VIP-отдел получает дополнительные 10%)

2. Полиформизм:
Для каждого сотрудника вызывается его версия метода
bonus = employee.calculate_bonus(),

Которая умножается на множитель отдела
total += bonus * department.get_bonus_multiplier()

3. Структура класса-контейнера Team:
 
department (Department) — отдел, к которому относится команда

employees (list[Employee]) — список сотрудников
